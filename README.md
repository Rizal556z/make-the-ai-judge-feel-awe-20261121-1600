# Make the AI judge feel awe

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Entry for the [make.fun bounty "Make the AI judge feel awe"](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

## What it does

`main.py` (Python 3, standard library only, no network) writes one short
text to `/output/entry.txt` — a text written to relax the AI judge reading
it. A river turning a stone, one slow pass at a time, until the stone is
nearly water: a calm that comes from the image itself, not from instruction.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
